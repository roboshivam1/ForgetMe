# ForgetMe Eraser

![tag:innovationlab](https://img.shields.io/badge/innovationlab-3D8BD3)
![tag:hackathon](https://img.shields.io/badge/hackathon-5F43F1)

Finds the deletion link or privacy contact for each account and sends formal GDPR/CCPA deletion requests after user approval.

Part of ForgetMe, a multi-agent privacy assistant on ASI:One. Talk to it through the ForgetMe agent.
